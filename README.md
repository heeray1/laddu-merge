# Laddu Merge

A merge-drop physics game with Indian sweets. Drop sweets into the jar; two same sweets merge into a bigger one, from Boondi up to the Maha Laddu.

Play: https://heeray1.github.io/laddu-merge/

- **Daily Thali**: a new game every day, with the same order of sweets for everyone.
- **Endless**: play as long as you can.
- One HTML file plus Matter.js (vendored in `vendor/`, MIT licence). Progress is saved on the device.

Testing: `index.html?bot=540` plays by itself (add `&mode=daily` for the Daily Thali).
